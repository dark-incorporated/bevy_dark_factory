## The comment survey (the owner's "no comments" question)

`CommentsRound2` counted comment lines per crate and classified them. The finding that matters is not the ratio: **23 of the stale comments found in this pass are load-bearing** — they state the *reason* a module exists (`keys.rs`'s focus argument, `activity_bar.rs`'s absent tabs, the manifest's Markdown decision) and the reason has expired while the code moved on. A rule that strips comments would have deleted those arguments *and* the 4,000 lines of invariant prose beside them that are right.

**Recommendation, with numbers:** do not adopt "no comments". Adopt a narrower rule the review can test: **a comment that names a symbol, a constant or a line number must resolve**, and the test that resolves citations in `layout-model.md`, `text-roles.md` and `data-files.md` (#586, #608) is the shape for it. That rule would have caught every one of the 23 without touching the prose that explains *why*.
